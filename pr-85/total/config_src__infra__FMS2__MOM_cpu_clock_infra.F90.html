5!> Wraps the MPP cpu clock functions
6!!
7!! The functions and constants should be accessed via mom_cpu_clock
8!!
9!! Compiling with -DMOM_USE_NVTX additionally emits an NVTX range around every MOM6 cpu
10!! clock, so each existing cpu_clock_id() name becomes a named range in an nsys timeline
11!! with no call-site changes. It requires nvfortran and the NVTX library
12!! (-DMOM_USE_NVTX ... -cudalib=nvtx). Undefined by default: a normal build compiles
13!! exactly as before and links no extra library.
